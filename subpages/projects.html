Howestprime

A cinema ticketing platform built as two .NET microservices, movies and ticketing, split along domain-driven bounded contexts. They only talk through a RabbitMQ topic exchange (contracts in AsyncAPI), so booking and payment run fully asynchronously. The whole Azure environment is defined in Terraform, and GitHub Actions tests and deploys every merge to main.

AI File Analyzer

A retrieval-augmented generation (RAG) tool that answers natural-language questions about your own documents and runs fully locally, so private data never leaves the machine. Documents are parsed with Apache Tika, chunked, embedded and stored in ChromaDB; the most relevant chunks are handed to Llama 3 as context, and it says so when the answer isn't in your files.

Splendor Online

A browser-based multiplayer version of the board game Splendor for up to four players. I worked on the Java server that enforces the rules and turn flow, and designed AI opponents that score every legal move on six weighted heuristics, with the weights tuned by a (1+1) evolution strategy.
